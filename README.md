One roast of the dullest object in my pocket, in a single 136-character line. It picks a detail the phone itself invented — the weekly Screen Time report — and turns the device into a prosecutor that files charges, serves the summons, and then graciously lets the guilty thumb dismiss them. `main.py` reads the line from `entry.txt` and writes it verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), byte-identical on every run.

## Run it

```sh
python3 main.py
```
